# EnglishApp

Học **câu tiếng Anh giao tiếp cơ bản theo chủ đề** — không học ngữ pháp rời, mà học câu dùng được ngay.

## Cách học

1. Chọn một tình huống thật: chào hỏi, quán cà phê, nhà hàng, mua sắm, hỏi đường, khách sạn, sức khỏe, công việc, gia đình, điện thoại, sân bay, khẩn cấp.
2. Đọc câu tiếng Anh, nghe phát âm, xem bản dịch và ghi chú khi nào dùng.
3. Luyện bằng **thẻ từ** (lật Anh ↔ Việt) hoặc **trắc nghiệm** (thấy tiếng Việt, chọn câu tiếng Anh).
4. Trả lời đúng 2 lần liên tiếp thì câu được đánh dấu **đã thuộc**. Các câu đang học dở nằm ở tab **Ôn tập**.

Tiến độ và câu đã lưu được giữ trên máy (localStorage), không cần tài khoản.

## Chạy local

```bash
npm install
npm run dev
```

```bash
npm test
npm run build
```

Mở app trên điện thoại: giao diện ưu tiên màn hình nhỏ, nút đủ lớn để bấm, có nút nghe câu bằng Web Speech API.
