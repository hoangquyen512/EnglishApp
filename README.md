# EnglishApp

Học **câu tiếng Anh giao tiếp cơ bản theo chủ đề** bằng flashcard giống học từ vựng.

## Cách học

1. Chọn một chủ đề: chào hỏi, quán cà phê, nhà hàng, mua sắm, hỏi đường, khách sạn, sức khỏe, công việc, gia đình, điện thoại, sân bay, khẩn cấp.
2. Mỗi thẻ gồm **câu tiếng Anh**, **phiên âm**, **nghĩa tiếng Việt**, **hình minh họa** và **audio**.
3. Bấm **Nghe** (hoặc để thẻ tự đọc) rồi vuốt sang thẻ tiếp.
4. Luyện thêm bằng **trắc nghiệm**. Trả lời đúng 2 lần liên tiếp thì câu được đánh dấu **đã thuộc**.

Tiến độ và câu đã lưu được giữ trên máy (localStorage), không cần tài khoản.

## Chạy local

```bash
npm install
npm run dev
```

```bash
npm test
```
