# Yume

Daily English check-in with **Sora** — a companion who listens first and helps your English only when you tap a chip.

## Scripts

```bash
npm install
npm test
npm run dev
```

Open `http://localhost:3000`. UI is Vietnamese; chat bubbles are English.

Copy `.env.example` to `.env.local`. Without an LLM key, Sora uses a built-in fallback so the app still runs.
