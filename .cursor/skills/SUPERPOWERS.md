# Superpowers (project install)

Skills from [obra/superpowers](https://github.com/obra/superpowers) v6.3.0 (MIT).

Installed under `.cursor/skills/` so Cursor (including Cloud Agents) can load them in this repo.

On Cursor Desktop you can also install the marketplace plugin for session hooks:

```
/add-plugin superpowers
```

Core workflow: using-superpowers → brainstorming → writing-plans → TDD / executing-plans → verification-before-completion → finishing-a-development-branch.
